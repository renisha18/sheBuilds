# SheBuilds Chennai — Hero Section

A responsive frontend concept for the **SheBuilds Chennai** website, designed and developed as an open-source contribution.

The goal of this project is to create a bold, welcoming, and tech-focused visual identity that represents women who learn, build, connect, and lead in technology.

## ✨ Live Demo

🔗 **Hosted Website:** https://she-builds-brown.vercel.app

---

## 🎨 About the Design

For the design direction, we explored the existing SheBuilds visual identity and took inspiration from previous SheBuilds projects, particularly the idea of representing a woman actively building in technology.

The hero section combines:

- A warm, minimal background
- SheBuilds-inspired colours
- Bold typography
- A working woman in tech as the main visual
- Tech-inspired decorative elements
- Playful visual details
- Strong call-to-action buttons
- Responsive layouts for different screen sizes

The intention was to keep the interface **simple, expressive, and approachable** while still feeling distinctly tech-oriented.

---

## 🌸 Why We Built This

We wanted the hero section to feel like a visual introduction to the community itself — welcoming, energetic, creative, and rooted in technology.

We explored the existing SheBuilds design language before creating our own interpretation rather than starting from a completely unrelated visual direction.

💻 Getting Started
1. Clone the repository
git clone https://github.com/renisha18/sheBuilds.git
2. Navigate into the project
cd sheBuilds
3. Install dependencies
npm install
4. Start the development server
npm run dev
The application will be available at the local development URL shown in your terminal, usually:
http://localhost:5173
